# Project Instructions

- Keep code simple, client-ready, and focused on the current MVP stage.
- Do not commit secrets, API keys, tokens, `.env`, logs, or private credentials.
- Maintain clear separation between `src/bot`, `src/server`, and `src/miniapp`.
- Use TypeScript for application code.
- Use Google Apps Script Web App URL for future Google Sheets integration.
- Do not use Google Sheets API service account, private key, or client email integration.
- Keep MVP scope strict: no booking persistence, payments, or admin status flow until explicitly requested.
- Prefer small focused edits over broad rewrites.
- Keep UI clean, responsive, and suitable for a portfolio/commercial demo.
