# TutorBook Mini CRM — portfolio case

## Коротко

**TutorBook Mini CRM** — Telegram Mini App + bot/back-end для записи на занятия, консультации или услуги. Клиент выбирает формат, дату и время, оставляет контакт, а владелец получает заявку в Telegram и может подтвердить или отклонить слот.

## Бизнес-проблема

У репетиторов, экспертов и небольших образовательных проектов запись часто живёт в переписке:

- клиент спрашивает свободное время;
- преподаватель вручную проверяет слоты;
- контакты и комментарии теряются в чатах;
- подтверждение приходится отправлять отдельно;
- нет простого журнала заявок.

## Решение

Один понятный booking flow:

```text
Telegram bot -> Mini App -> выбор занятия/даты/времени -> контакт -> заявка -> Telegram admin notification -> Sheets/CRM
```

## Что показывает demo

- Mini App открывается как отдельный booking-интерфейс.
- Пользователь проходит пошаговую запись.
- Занятые слоты можно получать из внешнего источника.
- Заявка уходит на backend.
- Backend может передать запись в Google Apps Script / Sheets.
- Преподаватель получает Telegram notification с admin-действиями.

- beauty-мастера;

## Коммерческая ценность

- меньше ручной переписки вокруг свободного времени;
- клиент сразу видит доступный сценарий записи;
- владелец получает структурированную заявку;
- появляется минимальная Mini CRM-логика: слот, статус, контакт, комментарий;
- один сценарий можно переиспользовать для разных ниш.

## Demo vs production

В текущем виде это portfolio MVP. Для production-проекта под клиента обычно добавляются:

- реальные услуги и расписание;
- production Telegram bot token и webhook;
- Google Sheets / Airtable / database storage;
- домен и Vercel env variables;
- privacy/legal blocks для персональных данных;
- статусы обработки и follow-up;
- напоминания клиенту и владельцу;
- интеграция оплаты, если она нужна.

## Service package

Проект ложится в пакет **Booking / Mini CRM**:

- Mini App / форма записи;
- выбор услуги, даты и времени;
- заявка в Telegram;
- сохранение в таблицу/CRM;
- статусы обработки;
- инструкция владельцу.
