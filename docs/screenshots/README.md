# Screenshot checklist — TutorBook Mini CRM

Скриншоты нужны не для красоты, а чтобы portfolio case быстро объяснял рабочий сценарий.

## Минимальный набор

Готовые файлы в этой папке:

1. `01-welcome.png` — стартовый экран записи.
2. `02-lesson-type.png` — выбор типа занятия/услуги.
3. `03-date.png` — выбор даты.
4. `04-time.png` — выбор времени.
5. `05-contacts.png` — форма контактов.
6. `06-filled-form.png` — заполненная форма.
7. `07-confirmation.png` — экран проверки/подтверждения заявки.

Дополнительно для production/demo клиента можно добавить:

- `08-telegram-admin.png` — пример Telegram-уведомления владельцу.
- `09-sheets-row.png` — пример строки заявки в таблице/CRM.

## Как использовать

- 3–5 лучших скриншотов добавить в README или portfolio case.
- Не показывать реальные телефоны, Telegram IDs, токены, URL приватных таблиц или данные клиентов.
- Для demo использовать тестовые имена и замаскированные контакты.

## Что доказывают скриншоты

- пользователь может пройти запись;
- владелец получает структурированную заявку;
- данные можно сохранить в таблицу;
- проект готов к адаптации под клиента.
