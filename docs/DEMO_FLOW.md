# TutorBook Mini CRM — demo flow

## Цель demo

Показать, что это не просто форма, а короткий booking-сценарий:

```text
выбор занятия -> выбор даты -> выбор времени -> контакты -> подтверждение -> заявка владельцу
```

## Как показывать клиенту

1. Открыть live demo: https://tutorbook-mini-crm.vercel.app
2. Нажать **Начать запись**.
3. Выбрать тип занятия.
4. Выбрать дату из ближайших дней.
5. Выбрать свободное время.
6. Заполнить имя и телефон тестовыми данными.
7. Показать экран подтверждения.
8. Объяснить, что в production заявка уходит владельцу в Telegram и таблицу.

## Что проговаривать

- “Это можно адаптировать не только под английский, а под любую запись: консультации, фитнес, beauty, занятия, услуги”.
- “Главная польза — меньше ручной переписки и более аккуратная заявка”.
- “На старте делаем один простой сценарий, а потом добавляем статусы, напоминания, оплату или CRM”.

## Что не обещать как готовое без настройки

- реальные платежи;
- полноценную CRM;
- автоматическую синхронизацию со всеми календарями;
- production-хранение без настройки env и доступа;
- юридическую гарантию соответствия.

## Demo checklist

- live page opens;
- mobile layout readable;
- step flow works;
- unavailable/busy slots handled;
- contact validation works;
- build passes;
- README explains setup and environment variables.
